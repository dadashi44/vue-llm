# vue-llm: путь к v1.0

**vue-llm** — библиотека для Vue, чтобы легко встраивать в приложение чат с нейросетями (ChatGPT, Claude, Gemini, локальные модели через Ollama). Это аналог Vercel AI SDK, но для экосистемы Vue. Пишешь `useChat()`, и у тебя готов реактивный чат: ответ печатается по мере генерации, есть кнопка «стоп», повтор ответа и так далее.

Пакет опубликован в npm как `vue-llm`, код лежит на GitHub: `dadashi44/vue-llm`.

## Роадмап: 10 фаз

### До этой сессии (фазы 1–5, опубликовано до v0.5.0)

1. **Ядро:** `useChat` и провайдеры OpenAI, Anthropic, Ollama.
2. **`useCompletion`** (одиночный ответ без диалога) и **`useObject`** (модель возвращает JSON по схеме).
3. **Провайдер Google Gemini.**
4. **Middleware:** обёртки над провайдером для логов, заголовков и повторов.
5. **Серверная часть:** API-ключ хранится на сервере, а браузер ходит через прокси. Так ключ не утекает.

### В этой сессии (фазы 6–10)

6. **Вложения.** В чат можно отправить картинку, PDF, аудио или текстовый файл. Каждый провайдер принимает файлы в своём формате, библиотека сама их конвертирует.
7. **Сохранение истории.** Переписка переживает перезагрузку страницы (через localStorage или свой бэкенд).
8. **Повторы и лимиты.**
   - Если API вернул ошибку перегрузки (429/5xx), запрос автоматически повторяется с нарастающей паузой.
   - Можно ограничить частоту запросов и на клиенте, и на сервере.
   - Старый retry был сломан: он ждал, но запрос повторно не отправлял.
9. **Шаблоны промптов.** Можно написать `createPrompt('Переведи {{text}} на {{lang}}')`, и TypeScript сам проверит, что ты передал все переменные.
10. **Сайт документации.** 17 страниц на VitePress в папке `docs/`, деплоятся на GitHub Pages.
